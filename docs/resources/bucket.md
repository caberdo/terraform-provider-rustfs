# rustfs_bucket Resource

Manage S3 buckets in rustfs

## Example Usage

```terraform
# A basic bucket with tags and a region set at creation time.
resource "rustfs_bucket" "example" {
  name             = "my-bucket"
  object_ownership = "BucketOwnerEnforced"

  create_bucket_configuration = {
    location_constraint = "eu-west-1"

    tags = {
      env = "test"
    }
  }
}

# A bucket created with a canned ACL and legacy grant recipients. Changing the
# ACL or a grant updates the bucket in place with PutBucketAcl. RustFS 1.0.x
# accepts these values but reports only the owner grant back, so Terraform keeps
# the configured value and cannot detect an out-of-band ACL change.
resource "rustfs_bucket" "public" {
  name             = "my-public-bucket"
  acl              = "public-read"
  object_ownership = "BucketOwnerPreferred"

  grant_read         = "uri=http://acs.amazonaws.com/groups/global/AllUsers"
  grant_read_acp     = "uri=http://acs.amazonaws.com/groups/global/AllUsers"
  grant_full_control = "emailaddress=ops@example.com"
}

# A bucket with S3 Object Lock enabled. Object Lock can only be switched on at
# bucket creation time and can never be disabled afterwards.
resource "rustfs_bucket" "locked" {
  name                           = "my-locked-bucket"
  object_lock_enabled_for_bucket = true
}

# A bucket Terraform may destroy while it still holds data. force_destroy
# deletes every object, object version and incomplete multipart upload first;
# without it a non-empty bucket fails with BucketNotEmpty.
resource "rustfs_bucket" "scratch" {
  name          = "my-scratch-bucket"
  force_destroy = true
}
```

## Schema

### Required

- `name` (String) Name of the bucket

### Optional

- `acl` (String) Canned ACL for the bucket (for example private, public-read, public-read-write or authenticated-read). Applied at creation and on change; RustFS 1.0.x reports only the owner's FULL_CONTROL grant back, so the provider cannot verify the value or detect an out-of-band ACL change.
- `bucket_namespace` (String) Namespace the bucket is created in: account-regional or global.
- `create_bucket_configuration` (Attributes) Additional bucket creation options (region and tags). (see [below for nested schema](#nestedatt--create_bucket_configuration))
- `force_destroy` (Boolean) Delete every object, object version and incomplete multipart upload in the bucket before destroying it. This attribute causes data loss: without it, RustFS refuses to delete a non-empty bucket with BucketNotEmpty and the destroy fails.
- `grant_full_control` (String) Grantee to whom the full control permission on the bucket is granted. Applied at creation and on change; RustFS 1.0.x does not report ACL grants back, so the value cannot be drift-checked.
- `grant_read` (String) Grantee to whom the read permission on the bucket is granted. Applied at creation and on change; RustFS 1.0.x does not report ACL grants back, so the value cannot be drift-checked.
- `grant_read_acp` (String) Grantee to whom the read ACL permission on the bucket is granted. Applied at creation and on change; RustFS 1.0.x does not report ACL grants back, so the value cannot be drift-checked.
- `grant_write` (String) Grantee to whom the write permission on the bucket is granted. Applied at creation and on change; RustFS 1.0.x does not report ACL grants back, so the value cannot be drift-checked.
- `grant_write_acp` (String) Grantee to whom the write ACL permission on the bucket is granted. Applied at creation and on change; RustFS 1.0.x does not report ACL grants back, so the value cannot be drift-checked.
- `object_lock_enabled_for_bucket` (Boolean) Whether S3 Object Lock is enabled for the new bucket. This can only be set at creation time.
- `object_ownership` (String) Object ownership setting for the bucket: BucketOwnerPreferred, ObjectWriter or BucketOwnerEnforced.
