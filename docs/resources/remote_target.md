# rustfs_remote_target Resource

Manage remote targets used as replication destinations or notification ARNs in rustfs.

RustFS refuses to change the endpoint, credentials or TLS settings of a target that belongs to a site-replication peer: such a target records the peer's deployment id and follows the site topology. Those settings are edited through `rustfs_site_replication` instead; this resource keeps managing ordinary targets. A peer-owned target can still be read, but an in-place update of it fails with a diagnostic naming the peer deployment id (or the peer segment of its ARN) before any request is sent.

## Example Usage

```terraform
resource "rustfs_bucket" "source" {
  name = "source-bucket"
}

resource "rustfs_bucket_versioning" "source" {
  bucket = rustfs_bucket.source.name
  status = "Enabled"
}

# A target that RustFS derives from a site-replication peer belongs to that
# peer: its endpoint, credentials and TLS settings follow the site topology, and
# updating them here fails with a diagnostic naming the peer deployment id.
# Change such a target through rustfs_site_replication instead.
resource "rustfs_remote_target" "peer" {
  type          = "replication"
  endpoint      = "https://peer.example.com"
  access_key    = "peeruser"
  secret_key    = var.peer_secret
  secure        = true
  bucket        = rustfs_bucket.source.name
  target_bucket = "backup"
  depends_on    = [rustfs_bucket_versioning.source]
}
```

## Schema

### Required

- `access_key` (String, Sensitive) Access key for the remote target.
- `bucket` (String) Source bucket on which the remote target is registered.
- `endpoint` (String) Endpoint of the remote target, reachable from the rustfs server.
- `secret_key` (String, Sensitive) Secret key for the remote target.
- `target_bucket` (String) Destination bucket on the remote target.

### Optional

- `path` (String) Path prefix on the remote target.
- `region` (String) Region of the remote target.
- `secure` (Boolean) Use TLS for the remote target connection. Defaults to true.
- `type` (String) Remote target type. Only 'replication' is supported by this server version.

### Read-Only

- `arn` (String) ARN assigned by the server to the remote target.
