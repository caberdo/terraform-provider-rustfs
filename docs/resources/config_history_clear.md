# rustfs_config_history_clear Resource

Delete every stored server-config snapshot (DELETE /rustfs/admin/v3/clear-config-history-kv). This is destructive: all rollback points recorded in `rustfs_config_history` are deleted, so `rustfs_config_restore` can no longer reach them and an earlier configuration mistake can no longer be rolled back through the provider. The server returns an empty 200 without a count, so the only recorded result is when the clear ran. The action is one-shot: Read only echoes the recorded result, Delete is a no-op, and changing `triggers` runs the clear again.

## Example Usage

```terraform
# Destructive and irreversible: every rollback point in the server's config
# history is deleted, so rustfs_config_restore can no longer reach them. confirm
# must be the literal "clear-config-history".
#
# This is an action, not managed state: Read only echoes the recorded result and
# Delete is a no-op, so destroying this resource never deletes history again.
# Change a trigger when you deliberately want to clear the history again.
resource "rustfs_config_history_clear" "purge" {
  confirm = "clear-config-history"

  triggers = {
    incident = "INC-1042"
  }
}
```
