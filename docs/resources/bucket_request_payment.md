# rustfs_bucket_request_payment Resource

Manage who pays for requests and data transfer on a bucket. `Requester` makes the bucket requester-pays: every request must then be signed by a caller that accepts the charge. The default, `BucketOwner`, bills the bucket owner. Destroying this resource restores `BucketOwner`; the bucket itself is never deleted.

## Example Usage

```terraform
# Make a bucket requester-pays: every request must then be signed by a caller
# that accepts the charge. Destroying this resource restores BucketOwner.
resource "rustfs_bucket" "requester_pays" {
  name = "my-requester-pays-bucket"
}

resource "rustfs_bucket_request_payment" "requester_pays" {
  bucket = rustfs_bucket.requester_pays.name
  payer  = "Requester"
}
```
