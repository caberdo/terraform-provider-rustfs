# rustfs_kms_backup Resource

Create one RustFS KMS backup bundle under the server's configured backup root.

This records the bundle's metadata. The server exposes no route to read, verify or delete a specific bundle, so refresh only reports whether the backup subsystem is still available, and destroy only forgets the record; the bundle stays on the server.

Create first asks `GET /rustfs/admin/v3/kms/backup` whether the server can export. When it reports `export_supported = false` the apply fails with the server's reason and names `RUSTFS_KMS_BACKUP_DIR`, `RUSTFS_KMS_BACKUP_KEK` and `RUSTFS_KMS_BACKUP_KEK_ID`, and no bundle is written.

The create route returns identifiers and metadata only, never key material, so no secret enters state. Supplying an explicit `backup_id` is required: the server refuses to mix bundles in a non-empty destination, so a deterministic name is what makes a retry fail loudly instead of leaving a second orphan bundle.

Restore is not managed by this provider. It destroys and replaces key material, requires the backup id and conflict policy as separate confirmations, and needs the KMS master key out of band.

## Example Usage

```terraform
# Create one KMS backup bundle under the server's configured backup root.
# The server returns metadata only; no key material reaches Terraform state.
# There is no admin route to delete a bundle, so destroy only forgets the
# record. Restore is not managed by Terraform: it is destructive and requires
# the backup id and conflict policy as explicit confirmations.
resource "rustfs_kms_backup" "nightly" {
  backup_id = "nightly-2026-10-20"
}
```

## Schema

### Required

- `backup_id` (String) Bundle name under the server's backup root. Must be a single path component of letters, digits, dots, dashes and underscores, and must not start with a dot. Changing it creates a new bundle.

### Read-Only

- `artifact_count` (Number) Number of artifacts sealed into the bundle.
- `backup_kek_id` (String) Identifier of the backup KEK that sealed the bundle. Not the key material.
- `backup_kek_version` (Number) Version of the backup KEK that sealed the bundle.
- `deployment_identity` (String) Deployment identity the bundle is bound to; a restore refuses a foreign bundle.
- `export_supported` (Boolean) Whether the server can still export a bundle. A bundle cannot be verified individually.
- `id` (String) Terraform resource ID; the bundle's backup id.
- `manifest_digest` (String) Digest of the bundle manifest.
- `sanitized_config_included` (Boolean) Whether the bundle carries a sanitized KMS configuration artifact.
- `snapshot_generation` (Number) Monotonic snapshot generation recorded in the bundle manifest.
- `unavailable_reason` (String) Why export is unavailable, when it is.
