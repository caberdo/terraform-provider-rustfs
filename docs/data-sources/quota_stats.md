# rustfs_quota_stats Data Source

Read the quota subsystem's view of one bucket (GET /rustfs/admin/v3/quota-stats/{bucket}). This differs from `rustfs_bucket_usage`: `rustfs_bucket_usage` reports the scanner's eventually-consistent accounting (cached for up to 30 seconds, with `sets_reporting`/`sets_total` telling you whether the answer is complete), while `rustfs_quota_stats` reports the quota subsystem's own view, whose usage may be reservation/ledger based. A field the server cannot report is null, never zero. A missing bucket fails the read with the server error instead of reporting zeros.

## Example Usage

```terraform
# The quota subsystem's view of one bucket: its configured hard quota and the
# usage it accounted. Unlike rustfs_bucket_usage (the scanner's
# eventually-consistent accounting), this read is what quota admission uses, so
# it can be reservation/ledger based. A field the server cannot report is null.
data "rustfs_quota_stats" "logs" {
  bucket = "logs"
}

output "logs_quota" {
  value = {
    limit      = data.rustfs_quota_stats.logs.quota_limit
    usage      = data.rustfs_quota_stats.logs.current_usage
    remaining  = data.rustfs_quota_stats.logs.remaining_quota
    percentage = data.rustfs_quota_stats.logs.usage_percentage
  }
}
```

## Schema

### Required

- `bucket` (String) Name of the bucket to read the quota statistics for.

### Read-Only

- `current_usage` (Number) Usage in bytes as the quota subsystem sees it. Null when the server could not report a usage figure (for example a bucket admitted only by the reservation ledger), never silently zero.
- `id` (String) Data source identifier, the bucket name that was read.
- `quota_limit` (Number) Configured hard quota in bytes. Null when the bucket has no quota configured; the server reports no over-quota flag, so compare usage against this value yourself.
- `remaining_quota` (Number) Bytes still allowed before the quota is reached. Null when the server could not report it, for example when no quota is configured.
- `usage_percentage` (Number) Usage as a percentage of the quota. Null when either the usage or the quota is unknown or the quota is zero.
