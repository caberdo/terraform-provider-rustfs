# rustfs_tiers Data Source

List the storage tiers `rustfs_tier` manages, with the backend type and the backend configuration the server reports for each one.

`GET /rustfs/admin/v3/tier` is the only route that returns a tier's backend configuration. The server already redacts the credentials it knows about, and the provider redacts them again on its side (`secret_key`, `session_token`, Azure `account_key`/`sas_token`, GCS `client_secret` and the AWS role tokens) so a server that stops redacting one key cannot leak it into Terraform state. Everything else is kept, so `config_json` still describes the backend.

This data source is read-only; manage tiers with `rustfs_tier`.

## Example Usage

```terraform
# List the storage tiers the server has configured. config_json is the backend
# object with every credential value replaced by REDACTED, so it is safe to
# inspect (and to write to outputs).
data "rustfs_tiers" "all" {}

output "tier_backends" {
  value = [
    for tier in data.rustfs_tiers.all.tiers : {
      name        = tier.name
      tier_type   = tier.tier_type
      config_json = tier.config_json
    }
  ]
}
```
