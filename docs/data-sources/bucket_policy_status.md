# rustfs_bucket_policy_status Data Source

Read whether the server considers a bucket public (`GetBucketPolicyStatus`). RustFS evaluates the bucket policy itself and is strict: on 1.0.1 through 1.0.3 it reports true only for a statement that grants `s3:*` on the bucket to an explicit `{"AWS": ["*"]}` principal. A public `s3:GetObject` policy, the string form `"*"` and canned ACLs all report false. Canned bucket ACLs are accepted by RustFS but not stored, so they never make this value true. Read-only.

## Example Usage

```terraform
# Ask the server whether a bucket is public. RustFS 1.0.x reports true only for a
# statement that grants `s3:*` on the bucket to an explicit `{"AWS": ["*"]}`
# principal; public s3:GetObject policies and canned ACLs report false.
data "rustfs_bucket_policy_status" "app" {
  bucket = "my-app-bucket"
}

output "app_bucket_is_public" {
  value = data.rustfs_bucket_policy_status.app.is_public
}
```
