# rustfs_bucket Data Source

Look up one S3 bucket in rustfs: whether it exists, when it was created and the region the server reports for it. Read-only; use the `rustfs_bucket` *resource* to manage a bucket.

## Example Usage

```terraform
# Look up a bucket without managing it. A missing bucket reports exists = false
# without an error, so this can drive a count or for_each decision.
data "rustfs_bucket" "logs" {
  name = "my-logs-bucket"
}

output "logs_bucket_creation_date" {
  value = data.rustfs_bucket.logs.exists ? data.rustfs_bucket.logs.creation_date : null
}
```

## Schema

### Required

- `name` (String) Name of the bucket to look up.

### Read-Only

- `creation_date` (String) Creation time the server reports for the bucket (RFC3339), empty when the bucket does not exist.
- `exists` (Boolean) Whether the bucket exists. A missing bucket reports false without an error, so the value can drive count and for_each decisions.
- `id` (String) The bucket name, which is the data source id.
- `region` (String) Region the server reports for the bucket, empty when the server reports none or does not implement the location lookup. An empty region means the endpoint's default region.
