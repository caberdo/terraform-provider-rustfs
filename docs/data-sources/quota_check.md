# rustfs_quota_check Data Source

Evaluate whether an operation would be admitted against a bucket's quota (POST /rustfs/admin/v3/quota-check/{bucket}). The check is read-only: RustFS computes the bucket's current usage and the admission decision without reserving bytes or changing quota, objects or usage. `usage_percentage` is not reported here; use `rustfs_quota_stats` for the percentage and the limit breakdown. A field the server cannot report is null, never zero.

## Example Usage

```terraform
# Ask the quota subsystem whether an operation would be admitted. The check is
# read-only: it changes no quota, object or usage. Unknown operation types are
# treated by RustFS as PUT; this provider accepts PUT, POST, COPY and DELETE.
data "rustfs_quota_check" "next_upload" {
  bucket         = "logs"
  operation_type = "PUT"
  operation_size = 1048576
}

output "upload_fits_quota" {
  value = {
    allowed   = data.rustfs_quota_check.next_upload.allowed
    remaining = data.rustfs_quota_check.next_upload.remaining_quota
    usage     = data.rustfs_quota_check.next_upload.current_usage
  }
}
```

## Schema

### Required

- `bucket` (String) Name of the bucket to evaluate the operation against.

### Optional

- `operation_size` (Number) Operation size in bytes. Defaults to 0, which asks whether any operation of that kind would be admitted. The check never changes usage.
- `operation_type` (String) Operation to evaluate: `PUT`, `POST`, `COPY` or `DELETE`. Defaults to `PUT`. RustFS treats an unrecognized value as `PUT`; the provider rejects values outside the list before sending the request.

### Read-Only

- `allowed` (Boolean) Whether the server would admit the operation against the bucket's current usage and quota.
- `current_usage` (Number) Usage in bytes the decision was based on. Null when the server could not report a usage figure, never silently zero.
- `id` (String) Data source identifier, `bucket/operation_type/operation_size`.
- `quota_limit` (Number) Configured hard quota in bytes. Null when the bucket has no quota configured.
- `remaining_quota` (Number) Bytes still allowed before the quota is reached. Null when the server could not report it.
