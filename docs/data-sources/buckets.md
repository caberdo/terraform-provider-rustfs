# rustfs_buckets Data Source

List every S3 bucket the RustFS deployment reports, sorted by name. The list carries the name and creation time the server returns; it does not issue a request per bucket.

## Example Usage

```terraform
# List every bucket the deployment holds, sorted by name. One ListBuckets call
# serves the whole list.
data "rustfs_buckets" "all" {}

output "bucket_names" {
  value = [for bucket in data.rustfs_buckets.all.buckets : bucket.name]
}
```
